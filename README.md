# Interactive C# Mind Map

Explore the evolution of C# through an interactive HTML tree covering language versions from C# 1.0 to C# 15.

## Features

- 🌳 Expandable and collapsible topic tree
- 📚 C# language features organized by version
- 🔗 Links to official Microsoft documentation
- 💻 Lightweight HTML, CSS, and JavaScript
- 📱 Responsive design for desktop and mobile
- 🎯 Useful for .NET developers, interview preparation, and learning C#

## Live Demo

Visit **The .NET Engineer** blog to explore the interactive mind map:  
https://thedotnetengineer.blogspot.com/

## Technology Stack

- HTML5
- CSS3
- JavaScript
